# Kampagne

Auswertung der laufenden Websprint-Kampagne.

- `pruefverfahren.md` — das Verfahren: Quellen, Kennzahlen, Schwellen, Diagnose
- `verlauf.csv` — eine Zeile je Tag; **leeres Feld heißt nicht erhoben**, `0` heißt gemessen und null
- `JJJJ-MM-TT.md` — der Tagesbefund

Ausgeführt mit `/kampagne` (Definition in `.claude/commands/kampagne.md`).
